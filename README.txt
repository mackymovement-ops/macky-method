MACKY MOVEMENT METHOD — BRANDED PRESENTATION WEBPAGES

READY TO DEPLOY
The folder is a complete static website. It does not require a server, database or build step.

PAGES
- /index.html                 Region selection page
- /local/index.html           South African presentation (12 slides)
- /international/index.html   International presentation (12 slides)

ALL 12 SLIDE IMAGES have been retained in original form, including the slide inserted after the cover. Only the final pricing slide differs between versions.

HOSTING
Upload the CONTENTS of this folder to the web root of any static hosting service: GitHub Pages, Netlify, Cloudflare Pages, your existing web server, etc.
Alternatively, deploy this as /method/ on your website and share /method/local/ and /method/international/.

To preview locally, open index.html in a browser (some environments restrict local navigation; a simple local web server works best):
  cd Macky_Method_Website
  python3 -m http.server 8080
  open http://localhost:8080
